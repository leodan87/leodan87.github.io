Política de Privacidad

Vida Hermes · última actualización: 30 de octubre de 2026

1. Quiénes somos

Vida Hermes es una aplicación de uso personal operada por su único dueño para su propio beneficio. No es un servicio comercial ni está abierto al público. Contacto: leogarcia.lsgg@gmail.com.

2. Qué datos de Google usamos

Con el consentimiento explícito del dueño, la aplicación accede a los siguientes datos de su propia cuenta de Google, mediante los permisos (scopes) indicados:

  • Lectura de Gmail (gmail.readonly): leer sus mensajes para revisarlos, buscarlos y resumirlos.
  • Envío de Gmail (gmail.send): enviar correos en su nombre cuando él lo solicita.
  • Lectura de Calendar (calendar.events.readonly): leer sus eventos para recordárselos y organizar su agenda.

3. Para qué los usamos

Los datos se usan únicamente para prestarle al propio dueño las funciones de asistente descritas arriba. No se usan para ningún otro fin.

4. Cómo se almacenan y protegen

  • Las credenciales de acceso (tokens) se guardan en el servidor privado del dueño, con permisos restringidos (solo el usuario del sistema puede leerlos).
  • No se mantiene una copia de los correos ni del calendario más allá de lo necesario para responder a cada petición del dueño.
  • No se transmiten los datos a servidores de terceros.

5. Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos, y no se transfieren fuera del entorno privado del dueño.

6. Uso limitado (Google API Services User Data Policy)

El uso que Vida Hermes hace de la información recibida de las APIs de Google se ajusta a la Google API Services User Data Policy, incluidos sus requisitos de Uso Limitado (Limited Use). En concreto: la información de Google solo se usa para las funciones visibles para el usuario descritas aquí, no se transfiere ni se vende a terceros, no se usa para publicidad y no la leen seres humanos salvo con el consentimiento del dueño, por seguridad, o cuando lo exija la ley.

7. Cómo revocar el acceso

El dueño puede retirar el acceso en cualquier momento desde la página de permisos de su cuenta de Google. Al hacerlo, cualquier credencial deja de funcionar de inmediato.

8. Cambios

Si esta política cambia, se actualizará esta misma página con una nueva fecha.
